# UNIVERSAL TAROT · INTEGRATED EDITION (로컬 단일 실행 프로그램)

> **"내면을 비추는 사유의 거울, 삶의 주도권을 되찾는 리딩"**  
> 본 프로그램은 **유니버셜 웨이트 덱**의 풍부한 도상 상징과 **관찰, 행동, 해석 조언**의 3단계 접근법을 결합하여, 질문자의 실제 고민과 긴밀히 연계된 대화형 조언을 제공하는 로컬 독립형 타로 플랫폼입니다.

---

## ✦ 초소형 파일 구성 (최소 파일 개수 & 무설치)

복잡한 패키지 설치(`pip install` 또는 `npm install`) 없이, 다음 **2~3개의 파일만으로 로컬 어디서든 즉시 실행**됩니다:

1. **`run.bat`**: **더블 클릭 한 번으로 자동 실행**되는 윈도우 원클릭 런처 (가장 추천).
2. **`app.py`**: 파이썬 3 표준 라이브러리(`http.server`, `socket`, `webbrowser`)만을 사용한 초경량 로컬 웹 서버 및 데이터 엔진 (외부 pip 패키지 의존성 0%).
3. **`index.html`**: 화이트 배경 & 블랙 유니버셜 카드 UI, 3D 플립, Web Audio API 사운드 신디사이저, 대화형 해석 엔진이 모두 내장된 완전 자립형 프론트엔드.

---

## ✦ 실행 방법

### 방법 1. 윈도우 원클릭 실행 (가장 간편한 방법)
- 폴더 내 **`run.bat`** 파일을 **더블 클릭**하세요.
- Python 환경을 자동 감지하여 로컬 서버를 띄우고, 기본 브라우저(크롬, 엣지 등)를 즉시 실행합니다.
- (시스템에 Python이 없거나 실행 권한이 없더라도 브라우저 모드로 자동 전환되어 100% 정상 작동합니다.)

### 방법 2. 파이썬 터미널 실행
```bash
python app.py
```
- 추가 라이브러리 설치 없이 기본 Python 3으로 즉시 구동되며, 가용 포트(기본 `http://localhost:8000`)를 찾아 브라우저 창을 자동으로 엽니다.

### 방법 3. 브라우저 직접 실행
- 폴더 내 **`index.html`** 파일을 더블 클릭하여 바로 열어도 모든 인터랙션(셔플, 카드 뽑기, 도감, 사운드, 해설)이 완벽히 작동합니다.

---

## ✦ 주요 기능 & UI 특징

1. **화이트 배경 & 블랙 유니버셜 덱 디자인**:
   - 깨끗하고 우아한 화이트 배경에 고급스러운 흑백 유니버셜 카드와 파스텔 보라 포인트 적용.
2. **홈 화면 3D 입체 덱 설정 버튼**:
   - 홈 화면 중앙 제목 바로 밑에 실제 누르는 듯한 입체감을 가진 덱 설정 버튼 배치 (역방향 여부, 메이저/마이너 덱 범위, 셔플 방식 변경).
3. **우측 상단 덱 도감 펼쳐보기**:
   - 상단 헤더 우측의 **[덱 펼쳐보기]** 버튼을 통해 전체 78장 카드 도감을 메이저/마이너 탭별로 확인하고, 각 카드의 상징과 상세 해설을 열람 가능.
4. **유저 질문 연계형 대화식 해설 & [관찰, 행동, 해석 조언]**:
   - 딱딱한 원문 나열 대신 질문자의 고민 분야(연애, 커리어, 재정, 선택 등)에 맞춘 다정한 공감 멘트와 구체적 1문장 실천 조언 제공.
5. **살아 움직이는 시네마그래프 & 3D 카드 인터랙션**:
   - 카드를 터치하거나 마우스를 올릴 때의 입체 회전 및 카드 상세 보기 시 은은한 오라와 미세 파동 애니메이션.
6. **내장 Web Audio API 사운드**:
   - 외부 음원 파일 다운로드 없이 브라우저 자체 오실레이터로 앰비언트 힐링 BGM, 카드 셔플음, 크리스탈 플립음을 100% 자체 합성.
7. **연계 질문(Clarifier) 심화 리딩**:
   - 첫 리딩 후 추가 질문 시 보조 카드를 한 장 더 뽑아 입체적이고 다각적인 심층 조언 도출.
